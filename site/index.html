开始之前

你可能还想知道

剩下的，交给 Agent 一步步引导。

我不会写代码，也能使用吗？+

可以。把上面的一句指令发给 Agent，它会先和你确定保存位置，再安装工具。完成后，在 Agent 软件中打开新建的 career-workspace 文件夹，新建对话并发送它给出的开始指令，就能开始整理经历。

需要先准备完整的简历吗？+

不需要。有旧简历或项目材料就交给 Agent，没有也可以从一段工作、项目或学习经历开始。简历照片、个人网页和项目链接都可以之后再补充。

我的资料会存在哪里？+

资料默认保存在你选定位置下的 career-workspace 文件夹中。可以只在本机保存，也可以让 Agent 引导连接自己的 GitHub 私人仓库，方便备份和换机继续。你使用的 Agent 如何处理对话与文件，由该客户端的设置和条款决定。

现在可以直接投递和跟踪岗位吗？+

当前可以整理经历、维护简历母版、生成不同版本、选择排版、导出文件和准备平台填写稿。岗位分析与求职跟踪仍在规划中，目前不包含自动填表或自动投递。
