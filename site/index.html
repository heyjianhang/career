开始之前

你可能还想知道

剩下的，交给 Agent 一步步引导。

我不会写代码，也能使用吗？+

可以。安装桌面版后，在软件里创建或打开工作区，再按提示连接自己的 Agent。桌面版已包含运行环境，无需单独安装 Node.js 或 npm，也不要求会 Git。你负责讲清经历、核对内容，命令操作交给 Agent。

软件自带 AI 吗？+

career 提供工作区、工具和协作指引，搭配你自己的 Agent 客户端使用。Agent 需要能读写本地文件、运行命令；模型服务由该客户端提供。

需要先准备完整的简历吗？+

不需要。有旧简历或项目材料就交给 Agent，没有也可以从一段工作、项目或学习经历开始。简历照片、个人网页和项目链接都可以之后再补充。

我的资料会存在哪里？+

资料保存在你创建工作区时选择的本地文件夹中。可以只在本机保存，也可以让 Agent 引导连接自己的 GitHub 私人仓库，方便备份和换机继续。你使用的 Agent 如何处理对话与文件，由该客户端的设置和条款决定。

能管理岗位和面试进度吗？+

桌面版可以用看板跟踪岗位阶段，关联简历，保存公司分析和每轮面试记录。你可以和 Agent 一起整理材料、准备面试，实际沟通与投递由你完成。npm 0.2.0 主要提供简历能力，暂不包含看板。

隐私与统计

你的简历和岗位资料保存在自己的工作区，不会因为访问官网而上传。

官网启用统计后，会记录页面访问和安装包下载点击、版本及架构，用于改进产品。下载点击不代表下载完成或安装成功。统计使用随机浏览器标识，不记录姓名、IP、完整来源网址或简历内容；不会发送给第三方分析服务。

浏览器开启 Do Not Track 或 Global Privacy Control 时，不发送统计。你也可以在这里关闭；关闭不会影响下载。
