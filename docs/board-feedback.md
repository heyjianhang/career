# 看板改版需求清单

更新：2026-10-14。

状态：用户已确认统一实施。B01–B05 已落地页面、CLI 与 Skill，并通过本机浏览器和安装包验证；具体数据契约见 [岗位工作区](opportunities.md)。

## B01 阶段与归档分离（已实施）

- 去掉“沟通中”，沟通记录放在岗位文档中，可发生在任意阶段。
- 看板阶段为：待评估、准备投递、已投递、面试中、Offer、已结束；任意阶段都可进入已结束。
- 已结束记录结果：未通过、主动放弃、岗位关闭、已入职。详细原因写入岗位概况 Markdown。
- 归档是收纳操作，独立于求职阶段和结果。归档后从日常看板收起，在归档视图找回；保留原结果及全部资料。
- 不因长期未回复、准备材料或模拟面试而自动判定未通过或改变实际阶段。Agent 根据用户确认或明确证据维护进展。
- 实施时同步页面、CLI、Schema、Skill、筛选和测试；处理旧 contacting／archived 记录的兼容，不推测或丢失历史求职结果。旧 contacting 读取为 applied，旧 archived 读取为 ended + archived；未知结果保留待确认，读取不重写原文件。

## B02 当前阶段选择组件优化（已实施）

用户指出岗位抽屉中“当前阶段”原生下拉菜单需要优化。截图中的系统菜单、蓝色选中项、边框与页面风格不协调。

- 优化阶段选择器的触发按钮和展开菜单，使高度、字体、间距、圆角、边框、箭头对齐与工作台一致。
- 展开菜单清晰区分当前选中、悬停和键盘焦点；保留键盘选择、Esc 关闭及窄屏适配。
- 与 B01 一起调整选项：“沟通中”移除，“已归档”不再作为阶段；选择“已结束”时衔接结果选择。采用自绘阶段菜单，已结束进入结果子菜单。

## B03 岗位抽屉宽度调整与记忆（已实施）

- 用户要求岗位详情抽屉宽度可以调整，并记住设置；通过拖动抽屉左边缘调整，松开后保存，切换岗位或重新打开页面沿用。
- 将界面偏好保存在个人工作区的 `.local/ui-preferences.json`，统一管理，不写入每张卡片的 Markdown。该目录已被工作区 Git 忽略；宽度属于当前设备的界面偏好，不随岗位资料同步。宽度写入 board.drawer_width。
- 设置合理的最小／最大宽度，并根据当前窗口限制实际显示宽度；窄屏使用全宽，不覆盖用户保存的桌面宽度。
- 放大预览与普通抽屉宽度分开：退出放大后恢复原宽度，不因放大操作覆盖已保存的设置。

## B04 分析正文保持自由（已实施）

- 岗位概况、公司分析、岗位匹配分析等正文以自由 Markdown 为主，允许段落、列表、表格、引用和链接，根据岗位与协作需要调整组织方式。
- Skill 可以提供写作提示和推荐提纲，但不强制固定章节、字段齐全或逐项填表；没有资料时不补写猜测，不为满足模板制造内容。
- 仅用于定位、筛选、排序、流转、关联与必要协作汇总的信息采用少量结构化元数据；正文不进一步拆成细碎的表单。

## B05 按轮次保留面试记录，准备与模拟可选（已实施，按最新确认采用两层导航）

- 用户提出真实面试每轮留存记录，并可自行选择是否进行面试前准备或模拟；不要求按固定流程完成所有步骤。
- “面试”Tab 采用两层：第一层逐轮列表，点击进入第二层单轮内容；第二层可切换记录／准备／模拟并返回列表，Esc 逐层返回。所有文档仍可从“资料”访问。
- 每个真实轮次使用独立目录，保留一份主要面试记录；准备文档按需生成，模拟可多次进行并分别留存。轮次名称允许用户自定，如技术一面、业务面、HR 面，不预设固定轮数。
- 仅轮次标识、名称、可选时间与实际状态等必要信息采用结构化；问题、回答、反馈、复盘和后续事项保持自由 Markdown，不强制提纲。采用 career-interview/v1 元数据，记录路径 interviews/<interview-id>/record.md。
- “准备本轮”或“模拟本轮”提供复制 Agent 协作指令入口，携带岗位、轮次及已有文档位置；Agent 按需读取招聘描述、公司分析、匹配分析、相关简历和之前轮次记录，维护同一份岗位资料。
- 没有邀请时也可进行岗位通用准备或模拟，不据此生成真实面试轮次；模拟不推进实际阶段，模拟表现不视为招聘方反馈，真实结果仅按用户确认或明确证据维护。
- 不预先批量创建空文档；用户可直接补记真实面试，再选择是否复盘或准备下一轮。CLI 提供 interview list/save/context，board overview 列出待进行轮次，opportunity context 包含轮次与文档入口，career-board Skill 说明完整流程。

本次不发布 npm 版本；验证结果归档到 docs/context.md。
