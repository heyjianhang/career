# career 品牌定位

career 是**与 Agent 协作的个人求职工作台**。围绕求职者的经历、目标和机会，把资料整理、简历准备、岗位分析、申请跟踪和求职复盘接成可以持续推进的过程。

本定位延续项目既有全景规划。简历是首先落地的入口；面向个人的求职管理是产品范围。当前可用能力与后续规划见[路线图](roadmap.md)。

“下一步”既指简历里的表达，也指下一次申请、沟通和职业选择。首页先说明个人求职价值，技术形式放在使用说明；不让工具名取代产品定位。

## 为谁解决什么问题

面向准备第一份工作、寻找新机会或希望长期保存职业经历的个人。不要求用户会编程、记住 CLI 命令或手动维护 Git；由具有文件和终端能力的 Agent 引导与执行。

求职信息往往散在旧简历、聊天、招聘页面与表格里。career 希望让同一段经历服务于多份材料，让每个岗位关联当时使用的简历、判断依据和后续进展，让中断后的协作能接着继续。

## 核心价值

- **经历有积累**：事实、来源与表达分别维护，补充新经历时无需重来。
- **机会有依据**：岗位判断能对应实际经历、用户偏好与待核实信息。
- **进展可追踪**：申请、沟通、下一步和结果落在同一条求职记录上。
- **资料归个人**：保存在自己的目录，可选同步到自己的私人仓库。
- **协作能继续**：Skills 提供方法，CLI 执行确定性操作，上下文记录进度。

前两项中经历整理与简历选材已有实现；岗位数据管理、申请跟踪和指标页面属于规划。介绍具体功能时必须附真实状态，不把品牌愿景当作功能已经上线的证明。

## 产品组织与命名

长期导航按用户任务组织：工作台、简历、岗位、求职跟踪、复盘。当前仅展示已交付入口；新增模块再加入导航，不放无法操作的占位页面。

| 用词 | 含义 |
| --- | --- |
| 职业资料 | 完整经历、来源、能力与可选素材 |
| 简历母版 | 从事实整理出的完整表达，用于后续选材 |
| 简历版本 | 面向某个岗位或用途的内容选择 |
| 排版样式 | 同一份简历的视觉布局 |
| 岗位分析 | 要求、偏好、证据和缺口的比较 |
| 求职跟踪 | 求职者自己的申请、沟通、面试与结果记录 |
| 平台填写稿 | 可复制到招聘平台的字段内容 |

招聘网站是信息与进展的来源。产品文案使用“求职跟踪”，避免把面向个人的产品介绍成企业的候选人管理系统。品牌不承诺保录用、固定匹配率或自动代聊。

## 视觉与语气

保留已选的纸张、卡片、连接线与绿色字标：纸张承载经历，卡片连接机会，线索体现持续推进。后续插图可增加岗位卡片、时间线和看板元素，保持同一风格。

- 主色：深森林绿 `#22352D`；强调色 `#3C604B`；浅鼠尾草绿 `#A2BB79`；纸白 `#F5F6F0`。
- 字标使用衬线风格，界面和中文说明保持清楚易读；字体资产许可按实际使用记录。
- 中文优先，平实、具体、从容。说明“下一步做什么”，少用技术口号和焦虑式表达。
- 展示真实产品截图；概念插图与功能截图分开，演示使用虚构资料。
- 当前品牌横幅继续使用“把经历，写成下一步。”；页面文字补齐完整求职范围。
