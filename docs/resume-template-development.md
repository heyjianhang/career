# 从参考截图新增简历排版样式

这是仓库开发流程。用户提供截图后复现排版，模板接收既有内容和可选照片；访谈、选材和平台写作仍在对应 Skill。没有具体截图时先保留现有样式，不凭空决定下一种版式。

## 参考与布局

保存用户指定的参考页面链接、截图来源与预期效果到开发记录。区分“简历纸张的样式”和“网站编辑器的界面”，本项目新增的是可打印的简历排版。截图里的姓名、照片和经历只用于理解布局，不进入用户简历或公共演示。

从参考图核对纸张比例、页边距、单栏／双栏、信息顺序、字号字重、行距、色彩、分割线、照片比例和裁切。清晰整页图可直接实施；小缩略图无法确定的细节说明为近似，影响布局的缺失再请用户补图。允许浏览器渲染和可用字体带来细微差异，不保证仅凭截图逐像素相同。

## 唯一接入位置

- 注册接口：`src/presentation/templates/registry.ts` 的 ResumeTemplate，参照已有模板及 [扩展契约](presentation.md#模板扩展接口)。
- 每种样式有稳定 id、name、version、description、tags、photo、css 和 render；新增后递增版本只用于后续实际版式变更。themes 命令和样式库从注册表读取，不另写固定按钮列表。
- render 接收统一 ResumeContent 与已解析 ResolvedAssets；只能使用传入内容。正文转义，链接／联系方式遵循现有渲染约定，不能读取工作区或访问远程资源。
- CSS 限定在 `.resume-paper[data-template="<ID>"]` 内，避免改到工作台、平台稿或其他样式。字体本地可用且有许可；不从参考站热链私有字体、照片或模板资产。
- 照片标记 optional 或 none。optional 缺图时自然收回空间；有图使用传入的焦点裁切。none 的样式不获取照片，也不能静默删除经历以腾出版面。

内容包保存经历与表达，排版模板保存视觉规则；同一份包换样式不复制或新增母版。任意照片、教育、工作、项目、技能等章节能从统一输入接入，模板不得硬编码某个演示姓名或只渲染已知两种项目。平台填写稿仍按平台规则渲染，不受新视觉模板影响。

## 分页与交付标准

主预览、放大预览与打印快照通过 `pagination.ts` 共用 Paged.js 分页，固定 A4；默认 14mm 页边距，带页脚的命名页可增加下边距；窄屏缩放纸张，不改变分页。缩略图、放大预览、附件主预览与打印快照调用同一模板；支持内容自然续页，不用固定纸张高度、overflow:hidden 或自动删字冒充一页。长链接、中文段落、空选填项和无照片时仍可读；双栏需实际验证分页与文本阅读顺序。

用合成内容检查短文、长文、有／无照片，运行 npm test 和 npm run test:browser；现有测试不会自动充分覆盖新模板，需要为新样式补充导出、章节保留和布局检查。实际渲染新样式 PDF，核对文字可选、照片位置、项目未漏、无截断／重叠／空白续页，再交付选定样式的预览与导出。只增加截图图片作为背景不算可复用模板。

完成后提供新样式 ID、预览入口和检查结果；用户后续可在样式库应用或设为默认。已有快照不重写，重新生成的内容包集合即可看到新样式。

## 首批实现与回归入口

已内置的参考映射、稳定 ID、素材和差异见 [样式目录](resume-templates.md)。首批实现复用 `selected.ts` 的通用正文渲染，`selected.css` 为公共规则、`variants.css` 为有作用域的差异规则，全部经注册表提供给同一构建。新增另一种结构可以单独实现 `ResumeTemplate`，无需修改 Agent 输入。

在现有检查外运行 `npm run test:templates`；当前矩阵包含 12 种新样式 × 有照片／无照片／长内容，生成 36 份 PDF 和截图。自动检查覆盖完整章节、照片焦点、长链接溢出、样式交互和预览／PDF 页数一致；仍需渲染检查分页、字形和视觉层级，不以 PDF 文件存在代替视觉验收。

合成样例还包含四行技能与四行荣誉，验证短资料按行保持完整、标题和说明同行、长叙述保留，以及黑白细线不会因这些短字段产生稀疏的额外一页。紧凑布局只由输入结构推导，日期类旧段落不回写为 period；增加新的推导规则时覆盖混合字段、链接、多段和超长内容，避免丢失语义。模板布局变化递增模板版本，不改已有内容或冻结快照。

空值显示统一在 presentation/content.ts：renderTemplate 在调用每个模板前生成展示副本，不能删改源包。新增模板同样必须隐藏空 heading／role／contacts，不硬编码“核心技能”等章节名称。运行 node tests/resume-empty-browser.mjs 覆盖 14 种样式的空栏目 PDF；仅标签无值的通用字段在统一包投影时省略。当前 classic／compact 为版本 5，12 款选定样式为版本 6；简约研发 engineering 为版本 4。新增模板保留 technologies 和 page_break_before，并支持 layout 字体／行距覆盖及照片 zoom。

简约研发的分页产物回归可运行 `npm run build && node tests/pagination-pdf.mjs`，覆盖短项目、超过整页的长介绍／长要点、续页标题、文本完整性和手动换页；带照片、技能网格与连续雇主的对照用例同时核验自然流排版、固定间距、页数及手动分页。该检查调用生产 PDF 导出器，输出到独立临时目录，不改用户资料。

所有模板遵循同一阅读顺序：经历标题、角色、技术栈与链接作为开头跟随正文，正文按段落／要点自然续页，至少保留两行；短资料列表按行保持完整，不再整组强制同页。跨页经历显示名称与“（续）”。简约研发使用固定间距和自然流排版，禁止按页拉伸间距、按内容量压缩间距或为了末页均衡强制换页。其他模板暂保留原有有限留白均衡，紧凑样式与手动换页保持原意。字号、行高、正文和顺序不变；详见 [分页优化](plans/engineering-pagination.md)。

主预览、样式放大和编辑器共用 `preview-viewport.ts`，按实际缩放纸张宽度居中；适应宽度扣除容器内边距，超宽页面允许两侧滚动，缩放保持阅读位置，翻页计入纸张起点。预览裁剪仅限制 iframe 未缩放的布局盒溢出，不裁剪纸张或正文。

全模板离线回归：`node tests/pagination-pdf.mjs .cache/pagination-all --all-templates`，覆盖 15 款 × 5 组资料，共 75 份 PDF；检查正文完整、续页、手动换页和自然留白。使用新的输出目录以保留先前产物。

简约研发专项：`node tests/engineering-pdf.mjs`，使用五组合成内容验证连续流排版、追加后续内容不影响前面页面、文本完整、手动分页、紧凑密度和自定义字号；生成源码快照和 PDF 供预览逐页比对。`paginationDocument` 与其依赖都须通过 `paginationResources` 可序列化，不能引用只在服务器模块作用域存在的函数。
