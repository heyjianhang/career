# desktop 0.3.0-alpha.7 本地安装包

2026-10-16，调整空看板并增加逐列新建入口。Mac ARM64 本地预览包，未签名、未公证、未公开发布，来自当前未提交工作树；公开桌面版仍为 alpha.1，npm 仍为 0.2.0。

## 改动

没有岗位时默认展示六个阶段列和数量 0，首次添加指引放进“待评估”列。搜索或筛选无匹配结果时仍提供清除条件入口，不填充示例岗位。

每列标题右侧提供常驻的“＋”，支持鼠标、键盘及可访问名称。沿用现有 Agent 交接窗口，复制指令携带对应阶段；“已结束”要求先确认结束结果，全局添加仍默认“待评估”。点击入口或复制不会直接创建记录。看板复制使用既有原生剪贴板桥接，浏览器保留标准 API 和手动复制兜底。

继续包含 alpha.6 的简历卡片、alpha.5 的桌面布局、alpha.4 的填写稿复制、alpha.3 的短章节排版及 alpha.2 的启动恢复与图标调整。未修改资料契约或用户 Skills。
