# desktop 0.3.0-alpha.5 本地安装包

2026-10-16，统一桌面工作台的导航与顶部比例。Mac ARM64 本地预览包，未签名、未公证、未公开发布，来自当前未提交工作树；公开桌面版仍为 alpha.1，npm 仍为 0.2.0。

## 改动

展开侧栏由 196px 调整为 224–248px 的有界自适应宽度，品牌区与顶栏垂直对齐。看板、简历库、编辑、简历预览和资料页共用 workspace-header：桌面基础高度 64px、标题 20px、操作控件 36px，取代原先各页 84–88px 及不同的标题／控件尺寸。

收紧简历页签与导出栏的留白，统一水平边距；看板内容与顶栏保留 20px 间隔。窄屏允许工具栏换行，侧栏仍可折叠／覆盖展开；长简历标题在可用空间内省略，保留操作按钮。共享样式同时供浏览器和 Mac／Windows 桌面使用，不改变简历正文与 PDF 模板。

继续包含 alpha.4 的填写稿复制提示与原生字段复制、alpha.3 的短章节排版、alpha.2 的启动恢复与图标比例修正。
