# desktop 0.3.0-alpha.3 本地安装包

2026-10-16，针对简历预览中技能跨页、荣誉条目松散和额外留白的问题生成 Mac ARM64 本地预览包。未签名、未公证、未公开发布，来源为当前未提交工作树；公开桌面版仍为 alpha.1，npm 仍为 0.2.0。

## 改动

12 款选定模板更新为模板版本 2。简短的标题与说明使用紧凑行，日期说明使用名称与右侧时间；小型章节尽量整组分页。带副标题、链接、列表、多段或长文本的内容保留纵向结构与自然续页。布局按输入结构推导，不改写用户字段、正文或已有冻结快照。

黑白细线保留 9pt 正文，收紧页头、段落、条目与章节间距，增加章节细分隔线。同一合成案例从两页收拢为一页，技能与荣誉完整保留；不保证任意履历都能排成一页。继续包含 alpha.2 的启动恢复与图标比例修正。
