## 改动

卡片常规宽度由 300px 收窄为 280px，预览改为铺满卡片宽度、裁切第一页上方约 53%，去掉整张纸缩略图外围的留白。完整简历和 PDF 保持原样。名称单独一行，下方显示所选样式、真实页数与更新时间；加载或预览失败时不猜测页数，长名称支持悬停查看。

悬停、键盘聚焦或触屏时显示编辑和更多操作；更多菜单提供另存一份、导出 PDF，支持方向键、Escape 和 Tab。导出沿用当前样式并校验内容摘要，冲突时提示刷新。旧展示包通过编辑副本进入，保留原文件。

继续包含 alpha.5 的桌面布局比例、alpha.4 的填写稿复制、alpha.3 的短章节排版及 alpha.2 的启动恢复与图标比例调整。未修改资料契约或用户 Skills。
