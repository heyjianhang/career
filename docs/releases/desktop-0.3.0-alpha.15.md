# 桌面 0.3.0-alpha.15：Mac 签名与模型配置改进

状态：本地候选，尚未公开；官网继续提供 alpha.14。npm 保持 0.2.0。

## 变化

- Mac 预览包改为完整 ad-hoc 临时签名，覆盖应用资源与内部组件，保持 hardened runtime。
- 构建检查完整签名及资源封装，最终 DMG 只读挂载后再次校验；失败停止构建，验收报告随 CI 产物保存。
- 统一所有设置页外框，模型设置改为服务商连接与模型列表，支持百炼 Qwen 3.8 Flash／Max、DeepSeek、火山引擎与自定义兼容服务。
- 新增文本、视觉、实时语音三种默认用途；预置百炼 ASR 和豆包流式识别 2.0 小时版／并发版，火山语音 Key 独立配置；语音目前仅预配置，未接入录音或转写。
- 加密模型配置升级到 v2，迁移保留已有模型、默认选择和不同 Key；停用服务不可继续调用。
- 不修改用户工作区、资料或投递状态。

## 边界

预览包没有 Developer ID 证书及 Apple 公证。首次打开需要用户手动允许，不能承诺所有 macOS 版本显示相同提示。临时签名校验、打包应用功能测试和浏览器下载后的 Gatekeeper 验收分别记录；不能以清除隔离标记、关闭系统防护或直接运行内部二进制替代首次打开验收。

## 验证进度

- 218 项基础测试通过，包含配置迁移、共享 Key、能力区分及实际临时应用签名检查；追加供应商请求参数断言通过。模型与工作区浏览器回归通过，六个设置栏目在四个断点的几何一致。
- 新 Mac ARM64 应用与最终 DMG 内应用均通过 `codesign --verify --deep --strict`；DMG 只读挂载及镜像完整性检查通过。构建生成 `SIGNATURES-mac-arm64.json`。
- 实际打包应用在独立合成工作区通过 15 项功能检查及第二进程冷启动检查，覆盖空白工作区、内置 CLI、企查查凭据桥接、模型设置、JD 导入、简历/PDF 和重启恢复。首次运行在外部服务设置等待超时，同一产物重试通过；保留两次日志，不将该超时归因于签名。
- 浏览器下载后的首次打开仍未验收：通过 Chrome 自动化点击本机 HTTP 下载链接后，Chrome 显示下载被安全策略屏蔽；用户提供的 `chrome://policy` 截图未配置任何策略，不能认定为 `DownloadRestrictions`。下载尚未到达 macOS 首次打开步骤；具体拦截来源待确认，没有更改浏览器/系统安全配置。
- Windows 与 Intel Mac 尚未构建；尚未提交、推送或公开本候选。

最终火山语音配置候选重新打包并通过 15 项功能检查及冷启动，证据 `.cache/desktop-test-1792299681990`；包含仅语音配置、独立 Key 加密保存和重启后默认语音恢复。真实云端 Key 和流式语音未测试。
