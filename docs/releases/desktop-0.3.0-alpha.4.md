# desktop 0.3.0-alpha.4 本地安装包

2026-10-16，为通用资料和招聘平台填写稿增加复制提示。Mac ARM64 本地预览包，未签名、未公证、未公开发布，来源为当前未提交工作树；公开桌面版仍为 alpha.1，npm 仍为 0.2.0。

## 改动

在填写稿标题下显示复制图标及「点击字段内容即可复制，再粘贴到 BOSS 直聘对应栏目」提示，平台名称随页签切换；通用资料提示粘贴到招聘平台对应栏目。附件简历及没有可复制字段的空页面隐藏提示。导出 HTML 回到附件页时同步隐藏提示，再切换填写稿仍可显示。

保留原有单字段复制、键盘操作、选中文字及复制成功反馈。实际安装包检查发现浏览器剪贴板写入被桌面权限拒绝，现改为通过受信任主窗口的 IPC 写入纯文本，校验类型和长度，不向页面开放剪贴板读取；普通浏览器与离线 HTML 保留原有实现。继续包含 alpha.3 的短章节排版修正和 alpha.2 的启动恢复、图标比例修正，不改变用户简历内容。
