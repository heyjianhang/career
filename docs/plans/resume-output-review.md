# 简历生成检查与后续优化

2026-10-17，检查对象为生成器代码及合成资料，不对用户私人简历内容作判断。

## 已处理

- 可选章节未填／空条目／空白段落与要点不输出；14 个模板一致。
- 通用资料只有标签没有值不展示；联系方式和求职方向为空不占位。
- 草稿保留，部分条目与自定义内容保留，非空非法 URL 仍拒绝。
- 旧展示包可用空章节数组；空平台稿有明确空态。
- 编辑页说明留空行为；Agent 指引同步，避免填“待补充”等占位文本。

## 已有且复测通过

章节正文、长内容自然分页；照片可选与焦点；主预览／PDF 一致；样式保存；编辑冲突保护；四个平台稿更新；响应式布局。空栏目与模板矩阵共 50 份 PDF，146 项单元／集成测试；最终 Mac ARM64 包实际回归见 ../releases/desktop-0.3.0-alpha.9.md。

## 建议后续按优先级实施

1. 导出前检查：提醒缺姓名／联系方式、未完成占位文字、异常日期和需核对来源，仍允许保存草稿；事实是否正确由用户与 Agent 核对。
2. 章节与条目的显示开关、章节排序：投 Agent 岗位时突出相关项目，同时保留 ERP 等资产；不通过删除原内容实现精简。需定义统一内容契约与平台稿是否跟随的规则。
3. 排版预检：明确显示实际页数、孤立标题、过少内容的末页；提供预览与手动调整入口，保留完整正文，不自动删字硬压一页。

上述三项为建议，尚未实现。本次没有改用户真实履历、历史投递快照或冻结版本。
