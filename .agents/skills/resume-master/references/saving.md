# 母版的保存、展示与阶段标记

路径相对于个人工作区。模板随本 Skill 提供，记录格式由仓库共享契约维护。

## 保存位置

| 内容 | 保存位置与模板 | 关联方式 |
| --- | --- | --- |
| 模块顺序与入口 | `resume/master/index.md`，用 [索引模板](../templates/index.md) | profile_id 指向个人事实；sections 只登记真实记录 |
| 个人简介 | `resume/master/summary.md`，用 [简介模板](../templates/summary.md) | kind: summary，来源覆盖实际概括的事实 |
| 任职成熟表述 | `resume/master/employment/<id>.md`，用 [任职模板](../templates/employment.md) | kind: employment，source_ids 关联事实 |
| 项目成熟表述 | `resume/master/projects/<id>.md`，用 [项目模板](../templates/project.md) | kind: project，source_ids 关联事实 |
| 整份可读预览 | `resume/master-preview.md`，普通 Markdown 派生产物 | 根据索引组合事实字段和母版正文，无新实体 ID |
| 维护状态 | `resume/maintenance.md` | 事实 ID、母版 ID、待同步事项与里程碑 |

education、skill、language、certificate 在 sections 直接引用对应事实 ID。不要为它们创建校验器不支持的 master-entry kind。

## 写入与复核

1. 先读已有文件，沿用稳定 ID，保留本轮范围外的正文及未知字段。新条目替换模板占位符和日期；source_ids 只列实际使用的事实 ID。
2. 根据事实完成正文，再执行 `npm run career -- workspace hash --path "<事实相对路径>" --workspace "<工作区>" --json` 取得 data.sha256；多份事实逐份读取。已有批量脚本 `node scripts/hash.mjs <事实文件> [...]` 仍可用，但输出格式不同，不按统一 CLI JSON 解析。reviewable 条目的 based_on 必须覆盖其全部 source_ids；尚有阻碍准确表达的缺口保持 incomplete。
3. 更新索引时保留原有条目与人工排序意图，只添加／调整本轮需要的部分；删除用户材料需有明确意图，不能因本次未使用就移除。
4. 运行 `npm run career -- workspace check --workspace "<工作区>" --json`，修复本轮导致的结构错误。记录实际检查结果；告警逐项判断，旧版本等无关告警不自动阻塞当前范围，但必须明确范围。
5. 按索引组合可读预览，写入实际姓名／联系方式选择、教育与各经历正文。说明预览的来源和生成日期，内部 ID、摘要、追问与编辑建议放到清单／questions，不混进简历正文。空章节可省略。
6. 展示整份预览或本轮完整章节，与用户一起检查阅读效果。现有预览有手工修改时先读取并回收到相应事实／母版记录；未能解决差异时另存候选，不覆盖旧文件。预览为派生产物，不能建立第二份可独立漂移的事实库。
7. 保存维护清单、progress 的母版阶段及范围依据和本轮 state；不要因母版已生成反向完成尚未深入的资产阶段。预览不在现有实体扫描范围内；自动格式检查不证明预览与索引一致，Agent 需逐章对照。

## 初期维护完成标准

同时满足以下条件，才记录完成日期及此次覆盖范围：

- 维护范围已经盘点：基本资料和本次相关经历有实际记录；暂缓、不适用或明确不纳入本轮的内容有依据，没有把未盘点写成完成。
- 母版索引包含有效内容，引用的事实和条目存在且对应；并已生成可完整阅读的实际预览，空索引不满足。
- 展示内容中的重要身份、日期、职责和成果有依据，关键矛盾已解决或争议内容明确排除。非关键缺口可保留在 questions；不能把仍有争议的陈述写进正文后只标暂缓。
- 本轮范围的结构检查通过，内容已对照事实复核，并已向用户展示。无需额外审批来标记进展，但不能把用户沉默记成用户已确认；用户指出的未解决事实问题继续保持待处理。
- 已有母版的当前变更与预览同步，本轮没有遗漏的待更新事项；剩余问题和下一步明确可续接。

维护清单记录“初期维护：已完成”、日期、范围、当前母版状态和实际检查结果。后续新增经历保留原里程碑，单独维护本轮更新；完成本轮后恢复当前状态，不重复宣称整个职业历史永久完整。
