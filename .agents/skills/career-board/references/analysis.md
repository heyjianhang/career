# 公司与匹配：独立方法，上层编排

收到 JD 后的创建、去重、简历推荐和 subagent 分工见 [入库与分析编排](intake.md)。岗位首页只展示 job.md；判断保存在各自分析文档。

| 当前问题 | 使用 Skill／方法 | 产物 |
| --- | --- | --- |
| 公司怎么样，业务与团队是否适合 | [career-company](../../career-company/SKILL.md) | analysis/company.md：主体、证据、影响、未知 |
| 这份简历与岗位是否匹配 | [career-match](../../career-match/SKILL.md) | analysis/match.md：当前绑定版与 JD 的版本依据、要求对照、差距和建议 |
| 未绑定，想比较已有简历 | career-board 推荐版本，career-match 可逐份比较 | 候选报告，不冒充绑定版；用户选择后再关联 |
| 比较机会与综合推荐 | [共享评分](job-evaluation.md) | 能力与机会价值分别评价，不足时不评级 |
| 面试准备、诊断和模拟 | [面试协作](interview.md)、[考核方法](interview-assessment.md) | 按轮准备与独立模拟，不改变真实结果 |

正文自由组织，不必填满固定栏目。未知不能填成零分，关键词数量不能当胜任度。已有原文和用户手改保留；更新前读取最新内容与摘要。分析完成不自动改变用户星级、简历绑定、岗位阶段或投递状态。

完整评分演算见 [虚构案例](worked-example.md)。当前版本匹配与补充事实严格分开；旧案例展示证据评分机制，不授权跳过具体简历核对。
