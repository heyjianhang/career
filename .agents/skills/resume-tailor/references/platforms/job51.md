## 1. 证据与适用范围

| 标记 | 含义 |
| --- | --- |
| 页面确认 | 字段、提示、选项、计数器直接可见 |
| 控件属性 | 当前 DOM 输入控件属性或表单组件标记，不等于服务端规则 |
| 待核实 | 当前没有观察到，或涉及未展开的分支、提交后行为 |

下面表格的“必填标记”指字段所属表单项的 `is-required` 组件标记。“有”不代表已测试空值提交；“未见”也不能解释为选填。明确写有“选填”的字段单独说明。多数输入框没有 HTML `required`、`aria-required` 或 `maxlength`，不能据此认定无业务限制。

字数上限按页面计数器原样记录。没有输入超长内容，也没有验证换行、表情、组合字符的计数方式。文件大小沿用页面 K／M 单位，不擅自确定十进制或二进制字节换算与边界是否包含。

## 13. 对 career 平台稿与后续 HTML 的建议

本节是实现建议，不是当前已实现功能。

1. `job51` 拥有自己的字段映射和约束，不能直接复用智联模板。工作描述采用页面预算 2000，个人优势 500，项目描述 2000，作品描述 500，校内职务描述 2000；特殊字符计数策略仍待验证。
2. 工作经历的职责与产出合入“工作描述”；项目的背景、角色、职责与成果合入“项目描述”。每个实际输入框对应一个复制按钮／纯文本代码块。
3. 下拉、分类选择、单选和多选字段展示“待选择的值／匹配提示”，与可粘贴正文区分。城市与行业分别考虑 3 项上限；月薪和发薪月数分别输出。
4. 将“技能经验”保留为职位相关动态表单；将“专业技能”和“语言能力”分别映射，不能默认采用相同熟练度枚举。
5. 平台页面可分在线字段与附件两部分。附件预览显示实际格式、大小及平台要求；简历附件和作品集分别准备文件。
6. 资料缺失、词库无对应项、内容超长、必填标记冲突等写入内部说明。不能静默丢弃资料或用虚构内容填满表单。
7. 正式平台模板建立后再记录其 revision 和验证状态。本记录本身不等于已有机器适配器、HTML 生成器或自动填表能力。
