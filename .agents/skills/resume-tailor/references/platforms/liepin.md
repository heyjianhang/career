## 1. 证据与边界

“截图确认”表示用户截图中直接可见的字段、计数器、提示或控件；“待核对”表示未显示、未展开或无法据截图确定。没有检查 DOM 的 maxlength、required 等属性，也没有提交空值、超长文本或文件测试。

- 没有“选填”字样不能直接认定必填；没有字数提示也不能认定不限。
- 页面字数计数器与提示是当前已观察约束；表情、组合字符、换行等计数及服务端校验未测试。
- 文件大小沿用页面 M 单位，不推断十进制／二进制换算、最小大小或具体边界处理。
- 当前已填内容、勾选状态、推荐词条与完整度不能当作所有账号的默认值或用户已授权的选择。

三段正文分别组织，不能只生成一个通用项目描述：

- 项目职责：本人角色与责任、遇到的难点、采取的办法。

## 8. 资格证书与技能标签

### 资格证书

来源：L4。

- 选择弹窗有证书名称搜索、分类栏和具体证书条目。
- 页面直接显示 `已选（0/20）`，记录为当前选择器上限 **20 项**。
- 可见分类包括推荐、英语、外语、汉语、IT、项目管理、财会、统计、金融、法律、教育；不把截图可见部分当作完整类别全集。
- 部分语言证书条目包含分数或分数区间，例如雅思分数、托福分数段。匹配时保留真实成绩，不能只匹配考试名称或向上取档。
- 自定义证书、选择后的日期／成绩补充字段、附件证明与实际保存规则待核对。

### 技能标签

来源：L3。

- 弹窗标题旁明确写“最多可选10项”，页面上限为 **10 项**。
- 支持技能关键词搜索，并展示可选标签。
- 当前候选项来自一个具体页面状态，不代表所有岗位共用同一词表。
- 本图未显示熟练程度、使用时长或自定义新增操作；这些能力是否存在，仍待核对，不能认定平台不支持。

技能和证书属于选择器输出，生成器应给出真实、可匹配的候选值及选择提示，不能把所有标签合成一个需要粘贴的文本框。

## 9. 个人作品

来源：L1，三个分区分别有独立控件。

| 分区 | 页面要求 | 未核对 |
| --- | --- | --- |
| 图片作品 | 支持 JPG／PNG，大小不超过 **4M** | 图片数量、尺寸、像素、总大小、具体上传校验 |
| 链接作品 | 一个可见 URL 输入框，建议作品链接或个人主页 | URL 长度、协议限制、能否添加多条 |
| 附件作品 | 作品集支持 PDF，文件大小不超过 **20M** | 文件数量、最低大小、加密／扫描 PDF、具体上传校验 |

URL 提示中的网站地址只是示例，不作为用户的作品地址输出。一个可见输入框或上传按钮也不能用来推断只能保存一条记录。

个人作品区域的提示说明：主动投递、发送简历或同意招聘方索要简历时，附件会随在线简历发送；其他情况下招聘方不会看到附件。这是该区域的页面说明，不扩大为对所有资料、所有账号状态的隐私保证。

**附件作品与附件简历是不同模块。** L2 和 L10 中另外有附件简历入口，但没有打开对应上传说明。因此 PDF／20M 只用于本次已核对的附件作品，不能用来填写附件简历的格式与大小约束。

## 11. 对 career 的平台输出建议

本节是基于已观察字段的建议，尚未建立正式猎聘模板、自动填表器或 HTML 生成器。

| 约束对象 | 已观察规则 | 证据 |
| --- | --- | --- |
| 优势亮点 | 最少 10、上限 1000 字 | L10 |
| 工作职责业绩 | 上限 2000 字 | L8 |
| 项目描述 | 上限 1000 字 | L7 |
| 项目职责 | 上限 1000 字 | L7、L6 |
| 项目业绩 | 上限 1000 字 | L6 |
| 在校经历 | 上限 300 字 | L5 |
| 技能标签 | 最多 10 项 | L3 |
| 资格证书 | 页面上限 20 项 | L4 |
| 图片作品 | JPG／PNG，不超过 4M | L1 |
| 附件作品 | PDF，不超过 20M | L1 |
| 附件简历 | 格式、大小、数量未知 | L2、L10 仅见入口 |

1. 猎聘工作经历生成一个“职责业绩”正文；项目生成“描述、职责、业绩”三个正文，以及独立的项目职务和公司名称。统一内部事实，按平台调整组合，不能统一成相同输入框。
2. 教育长文本按 300 字选择相关职务、荣誉或课程；原始事实仍完整保留。削减内容和映射损失记录到内部说明。
3. 月薪下限、上限、发薪月数分别输出；期望地点与其他感兴趣地点分别提供选择提示。
4. 技能与证书按页面数量限制选择，词库匹配失败保留待确认；不得创造技能、证书、成绩或统招信息来补齐字段。
5. Markdown 按实际输入框提供独立的纯文本代码块；未来 HTML 对应独立复制按钮。标签、日期、复选框和上传控件另给操作提示。
6. 个人图片作品、链接作品、附件作品、附件简历分别组织。文件预览必须标明类型及已核对规则，不能只用一个“上传附件”通用约束。
7. 模板落地前继续记录证据、日期和未核对项。不能因为已有四个平台的资料文件，就把四个平台都标成完整验证通过。
