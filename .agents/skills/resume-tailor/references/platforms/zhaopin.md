# 智联招聘：在线简历填写格式核对

核对日期：2026-10-12（Asia/Shanghai）。平台 ID：`zhaopin`。

来源：[智联招聘·我的简历](https://i.zhaopin.com/resume)。使用已登录账号的电脑网页版，查看中文简历、“职场人”身份下的编辑表单、选择器和上传说明。

状态：已完成本轮页面观察；不等同于全部账号、学历分支和服务端校验通过。没有保存简历、上传文件或投递。本文件只记录平台规则，不保存账号标识、联系方式或个人经历正文。

## 1. 证据如何理解

| 标记 | 含义 |
| --- | --- |
| 页面确认 | 编辑表单、提示、选项或计数器中直接可见 |
| 控件属性 | 当前页面输入控件的 maxlength 等属性；不代表服务端所有限制 |
| 推算 | 从现有内容长度与剩余字数推算，需要单独注明 |
| 待核实 | 当前页面未给出，或没有通过本次观察覆盖 |

未知限制保持未知，不能写成“不限”。未测试表情、组合字符、换行等特殊计数，也没有尝试提交空表单或超长内容。不能把缺少 HTML required 属性解释成业务上选填。

## 2. 页面模块与顺序

当前中文页面依次为：

1. 基本信息。
2. 个人优势。
3. 求职状态。
4. 求职意向。
5. 工作／实习经历。
6. 教育经历。
7. 项目经历。
8. 培训经历。
9. 语言能力。
10. 专业技能。
11. 证书（右侧目录称“获得证书”）。
12. 个人作品／附件。

另有“简历管理”区域管理在线简历与附件简历，以及预览、下载和默认简历设置。页面存在中文／英文简历入口；本轮没有核对英文版。

页面直接标记“必填”的模块包括求职状态、求职意向、工作／实习经历、教育经历；页面完善提示也包含基本信息。这不等于这些模块内每个字段都必填。

## 3. 基本信息

| 字段 | 控件或填写方式 | 已观察到的说明 |
| --- | --- | --- |
| 姓名 | 文本 | 提示填写真实姓名，用于投递简历；长度待核实 |
| 性别 | 选项 | 男、女 |
| 当前身份 | 选项 | 职场人、学生；仅核对职场人分支 |
| 出生年月 | 日期选择 | 已有值采用年、月精度 |
| 参加工作时间 | 日期选择 | 已有值采用年、月精度 |
| 户口所在地 | 地区选择 | 地区层级选择，不能当作普通长文本框 |
| 现居住城市 | 地区选择 | 带“国外”复选项；海外分支未展开 |
| 政治面貌 | 选择项 | 存在该控件，未遍历选项 |
| 联系方式 | 展示与修改入口 | 修改链接进入账号设置；本轮未进入修改流程 |
| 电子邮箱 | 展示与修改入口 | 用于接收面试邮件；本轮未进入修改流程 |
| 头像 | 文件上传 | 页面明确写明仅 JPG、大小不超过 500k；建议一寸证件照 100×100 像素 |

生成器可提供文本复制值和选择提示；联系方式修改、身份选择和头像上传应作为独立操作，不混进“个人优势”。

## 4. 个人优势

只有一个多行文本框，编辑标签为“优势内容”。提示建议简短描述职业优势，并提示不要填写手机号、QQ、微信等联系方式。

| 项目 | 核对结果 |
| --- | --- |
| 输入形式 | 多行纯文本 |
| 长度 | 初步推算总量为 500：当前输入长度 300，页面显示还可输入 200 个字 |
| 证据等级 | 推算；不是空白输入框直接显示上限，textarea 也未声明 maxlength |
| 换行 | 当前已有正文包含换行；本轮未提交新的换行内容 |

生成时可以先按 500 的候选预算准备内容，但正式机器约束需要补充计数规则验证。不能把此推算写成已经通过服务端验证的硬限制。

## 5. 求职状态与求职意向

### 求职状态

页面确认四个选项：在职-正在找工作、离职-正在找工作、在职-看看机会、在职-暂不找工作。

### 全职意向

查看了已有全职意向的编辑表单。

| 字段 | 控件或规则 |
| --- | --- |
| 工作性质 | 当前显示全职 |
| 期望职位 | 职位选择控件 |
| 期望行业 | 多选，当前控件显示 3/3 |
| 期望城市 | 地区选择 |
| 薪资要求 | 最低、最高两个选择控件；展示区以元/月显示 |

当前页面显示“全职期望（3/3）”。记录为当前账号页面展示的全职期望数量上限，不外推到其他账号或所有工作性质。

### 新增入口中观察到的兼职分支

当前账号全职期望已满，从新增入口打开时显示兼职分支：

- 工作性质：兼职。
- 期望职位：选择器显示 0/5。
- 期望行业：选择器显示 0/3。
- 期望城市：地区选择。
- 兼职要求：上班时间、兼职时长等选择项，明确标注选填。
- 求职偏好：工作偏好、福利待遇等选择项，明确标注选填。
- 薪资要求：最低、最高选择项；此分支计薪单位未确认。

兼职的职位数量规则不能直接套到全职上。薪资数据也要保留对应的计薪单位，不能仅保存两个数字。

## 6. 工作／实习经历

分别查看了新增表单和已有经历编辑表单。

| 字段 | 控件 | 限制与观察 |
| --- | --- | --- |
| 公司名称 | 文本 | 控件 maxlength=100 |
| 所属行业 | 分类选择 | 需平台选项映射，未遍历全部行业 |
| 职位名称 | 分类／搜索选择器 | 打开后按职位分类选择，也可搜索；搜索框 maxlength=100 不等于职位名称字段上限 |
| 拥有技能 | 标签选择器 | 已有经历编辑中出现；新增表单初始状态未出现，可能受职位选择影响 |
| 在职时间 | 入职、离职日期 | 年月精度，带“至今”复选框 |
| 当前月薪 | 文本数字输入 | 页面单位“元”，提示明确选填，控件 maxlength=6；数值范围未测 |
| 工作描述 | 多行文本 | 空白新增表单明确显示“还可输入 3000 个字” |
| 本经历是实习经历 | 复选框 | 工作与实习使用同一经历表单 |

职位的展示区另有“职位类别”。已有职位名称可与类别名称不同，说明平台存在名称与分类的关系；本轮没有验证自定义职位名称的完整创建规则。

“拥有技能”弹窗会根据职业场景展示问项。本次开发类经历显示开发方向、编程语言、数据库等问项，每组显示最多 3 项，并提供自定义入口。该观察仅适用于当前职业分支，不应把开发技能列表固化为全职业公共字段。

### 生成规则

- 对外填写标签使用“工作描述”，输出一个连续的纯文本复制值。
- 职责、行动和成果可按自然段组织在该字段内。
- 行业、职位分类、技能标签另列选择提示；不能把这些控件当作普通复制框。
- 保留任职的真实日期与实习标记，不因格式适配改变身份或时间。

## 7. 教育经历

学历选项已经展开确认：初中及以下、高中、中专/中技、大专、本科、硕士、MBA/EMBA、博士。

本轮进一步展开了本科分支：

## 8. 项目经历

当前新增项目表单只有以下字段：

| 字段 | 控件 | 限制与观察 |
| --- | --- | --- |
| 项目名称 | 文本 | 占位提示“必填”；长度未明确 |
| 项目时间 | 开始、结束日期 | 带“至今”复选框 |
| 项目描述 | 多行文本 | 空白新增表单明确显示“还可输入 2000 个字” |

没有看到独立的“项目角色”“项目职责”“项目成果”输入框。

页面另有“填写文字在100个字以上评定等级，少于不计算，内容越详细，等级越高”的提示。这是平台的内容评价提示，不是已经验证的最小提交长度，也不是 ATS 得分或录用概率。

### 生成规则

将项目背景、本人角色、职责、行动和有依据的成果组织到同一个“项目描述”中。可以用自然段分隔，不在复制值中加入 Markdown 标题、列表语法或内部建议。

职业资料层仍保留角色、职责、成果等信息的结构；只在平台输出时组合，不为了该平台删掉源数据的结构。

## 10. 两种附件入口

### 附件简历

“简历管理 → 上传新附件”弹窗明确提示：

- DOC、DOCX、PDF。
- 中文简历。
- 大小不超过 20M（保留页面单位，未验证其字节换算与边界）。
- 支持拖拽或选择文件上传。

简历管理区同时展示在线简历与附件简历，存在“设为默认”操作。未核实附件简历总数量上限、重复文件处理、自动解析回填行为或各投递入口的默认选择规则。

本次仅打开上传说明，没有选择或上传文件。

### 个人作品

页面明确提示最多上传 10 个附件。新增编辑区中：

| 项目 | 观察 |
| --- | --- |
| 附件名称 | 提示至少 2 个字、不超过 20 字，输入控件 maxlength=20 |
| 支持类型 | 页面写明 PNG、JPG、Word、PDF、XLS、XLSX、TXT |
| 文件选择器属性 | accept 包含 image/*、Word/docx、PDF、XLS/XLSX、text/plain；multiple=false |
| 内部文件计数 | 编辑区显示 0/9；它与页面“最多10个附件”的具体层级关系待核实 |
| 单文件大小 | 当前页面未发现明确说明，待核实 |

不要因 accept=image/* 就承诺所有图片格式均可成功保存。也不能把附件简历的 20M 限制直接套到个人作品上。

## 11. 对 career 输出的影响

1. 智联需要专门的平台字段映射，不能直接使用通用模板的字段拆分。
2. 项目职责、角色、成果合入“项目描述”；工作正文映射为“工作描述”。
3. 教育模块按学历分支处理；本科分支中的“学位证书”使用有／无。
4. 求职状态、行业、职位、地区、掌握程度等属于选择项；HTML 应展示选择提示，文本字段才提供“复制正文”。
5. 时间按开始、结束、至今分别提供；结束时间与至今不能互相矛盾。
6. 本次可直接记录页面提示的工作描述 3000、项目描述 2000；个人优势 500 单独标为推算。字符计数与服务端提交仍未验收。
7. HTML 的“在线填写”与“附件简历”分开展示；切换 PDF 视觉风格不会改变在线字段内容。
8. 在线简历、附件简历、个人作品有不同用途与限制，不能混成一个上传配置。
9. 已复制不等于已在平台保存；生成器只能报告本地产物与复制动作。
10. 完整源资料继续独立维护；平台不支持的内容应在内部映射记录中说明，不静默丢失。

## 12. 待补验证清单

- 个人优势总量与特殊字符、换行的精确计数规则。
- 未明确标识字段的必填性，以及服务端最小／最大长度。
- 学生身份、其他学历和海外学习分支。
- 自定义职位名称与职位类别之间的填写流程。
- 不同职业的技能问项与自定义标签长度。
- 语种和读写能力的完整选项。
- 各重复模块的条目数量上限。
- 附件简历总数量、上传后的解析／覆盖行为、默认投递规则。
- 个人作品 0/9 的层级含义与单文件大小。
- 英文简历、手机网页和 App 的差异。

本轮核对可以支持第一版字段组织与页面设计。平台模板整体仍应保持“部分已核对”，不能标成所有字段、所有分支、所有提交规则均已验证。
