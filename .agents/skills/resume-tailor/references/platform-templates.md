# 平台填写模板

模板由本 Skill 的 `templates/platforms/` 维护；实际填写稿在工作区的 `resume/versions/<版本 ID>/platforms/<平台 ID>.md`，例如 `zhaopin.md`。一个版本可以有多个平台稿，各占一个文件；不同方向或岗位版本分别保存，不共用一个会被覆盖的全局平台稿。模板是规则，填写稿是某个版本的内容，两者不要混用。

模板记录平台、稳定字段 key、名称、顺序、内容形式、是否必填、已核实长度限制及来源、核对日期、修订号。未知限制用 null，不能用建议篇幅代替平台硬限制。

当前提供通用模板与智联候选模板。通用模板使用 not-applicable；智联候选模板仍为 draft，verified_at 为 null。2026-10-12 已逐模块查看智联求职者电脑网页，记录见 [智联填写格式核对](platforms/zhaopin.md)。记录区分页面确认、控件属性、推算和待核实，不代表服务端与全部分支已验证。旧候选模板尚未按本记录全面修订；生成新智联稿前先读核对记录，项目职责与成果合入项目描述，不能把旧模板中的独立字段当作实际平台控件。对某个平台读取到的招聘方简历结构不自动等于求职者填写规则。

2026-10-12 已核对前程无忧当前在校生身份、全职意向及各主要编辑模块，见 [前程无忧填写格式核对](platforms/job51.md)。该记录包含页面字数、选择器数量、附件要求与未核实项；项目所属公司的选填标签与组件必填标记存在冲突。本次页面观察不能标成全平台验证通过。

2026-10-12 已结合页面与用户截图核对 BOSS 直聘的个人优势、工作、项目及本科教育的可见字段，见 [BOSS 填写格式核对（部分完成）](platforms/boss.md)。个人优势页面上限为 1000，工作内容／项目描述分别为 3000，工作业绩／项目业绩分别为 1000，在校经历为 3000；正文与业绩分别输出。论文描述上限、个人信息编辑、期望职位及附件要求等仍待补。

2026-10-12 已根据用户提供的 10 张截图整理 [猎聘填写格式核对（截图覆盖范围）](platforms/liepin.md)。优势亮点为 10–1000 字，工作职责业绩合计上限 2000 字，项目描述／职责／业绩各 1000 字，在校经历 300 字；技能最多 10 项，资格证书选择器显示上限 20 项。个人作品中的 PDF／20M 要求仅适用于附件作品，不能代替附件简历的上传规则。基本信息编辑、语言、附加信息、附件简历与部分选择器仍待核对。

新增或更新模板时核对当前页面／可靠官方说明，记录出处与日期，递增 revision。填写稿记录实际使用版本；旧冻结版本不随公共模板更新而改变。

## 复制格式

- 一个平台输入框对应一个 `text` 围栏代码块。字段名称放在块外的标题中；公司、职位、日期和工作内容等独立字段分别提供代码块，不把整段经历合成一个复制块。
- 块内只放该字段可直接粘贴的纯文本。不用 Markdown 标题、加粗、列表标记、引用、表格、链接语法或 HTML；多条内容用自然段和换行。名称中的 C#、C++ 等字符及普通 URL 按原文保留。
- 多段工作、项目和教育经历在块外用标题分组。元数据、来源、说明、模板核对状态及复制指引均不进入代码块。
- 缺失字段不生成空块，也不填“待补充”等占位内容；具体缺口、模板限制和映射损失记录到同版本的 `notes.md`。代码块中的正文不包含 Agent 建议。
- 当前 v2 文件保留 YAML 元数据。用户复制各字段的代码块内容，不能把整份 Markdown 当作某个输入框的值。

以下为虚构的格式示例，具体字段仍以对应平台模板为准：

### 公司名称

```text
虚构湖岸书店
```

### 工作内容

```text
负责社区活动报名信息整理、到场确认与活动后反馈汇总。

与团队协作完成活动现场执行。
```

没有字段承载某段内容时记录信息损失，不能静默删掉或编造平台控件。成果页提供 Unicode 码点参考计数，不代表平台的精确计数算法；按核对记录继续复核。

## HTML 成果页使用的规则

`templates/platforms/render/` 提供四个平台主要字段的 JSON 规则，由 CLI 读取，均为部分覆盖：

- [BOSS](../templates/platforms/render/boss.json)
- [智联](../templates/platforms/render/zhaopin.json)
- [猎聘](../templates/platforms/render/liepin.json)
- [前程无忧](../templates/platforms/render/job51.json)

字段 key、标签、控件类型、已观察长度限制与核对日期在规则中维护；evidence 指向本目录 `platforms/` 内的核对记录。未知上限为 null；智联自我评价 500 是原页面推算，当前只写提示。规则不包含全部表单、枚举和必填验证，也不自动生成文案。已有 Markdown 候选模板与 v2 输出兼容保留；新的 HTML 内容包按 [成果页方法](presentation.md) 使用这些规则。
