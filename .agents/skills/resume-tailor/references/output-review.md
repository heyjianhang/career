# 输出前的四项复核

## 事实一致

将选中表述对照来源，检查个人与团队、日期、数量口径、技能熟练度及项目状态。新发现的事实回到 intake，不能只留在目标简历里。

## 岗位相关

核心要求是否有对应材料？证据不足项是否说明？次要经历是否占据过多篇幅？选材和省略能否从 notes 看懂？履历不同部分有没有互相矛盾？

## 阅读与复制

简历正文能够独立阅读。新版统一简历包由工具映射平台字段，不额外手写四份副本；检查实际生成的字段内容能直接复制、不混入内部说明、不显示空占位，和附件中的事实一致。只有维护既有 v2 文档时，才沿用 platforms/<平台 ID>.md 的逐字段 text 代码块规则。未知限制不能冒充官方限制，长内容不能静默截断。

已有岗位研究时检查选材能否追到要求和真实经历，未覆盖的关键要求如实留下；在研究报告登记简历包与取舍，不把报告或学习计划写成个人经历证据。

## 导出与留存

按 [CLI 操作](cli.md) 使用当前运行环境的导出能力。需要 PDF 时，导出后检查文件存在并核对中文字体、可复制文本、顺序、链接、页数、分页和溢出；外观和文本提取分别检查。失败时说明实际已交付内容和恢复步骤，不把 HTML 称为 PDF。不能保证所有 ATS 系统的解析结果。

留存前确认产物完整，之后修改建立新版本。CLI 生成成功、平台保存成功和真正投递成功是不同事件，分别按实际证据记录。
